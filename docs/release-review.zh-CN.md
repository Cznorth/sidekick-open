## 每次推送前

看 Git 实际要发布的内容（diff 和历史），而不是只看工作区。重点查：

- 人名、真实姓名、邮箱、电话、聊天软件账号；
- IP、内部主机名和域名、服务器路径、对应真实部署的端口；
- 凭据、令牌、密钥、Cookie、OAuth 文件；
- 真实记忆、聊天记录、附件、截图、健康或短信内容；
- 提交者元数据（本仓库用中性作者）。

提交前先机械过一遍：

```sh
git diff --cached | grep -nE '@|https?://|[0-9]{1,3}(\.[0-9]{1,3}){3}'
```

剩下的链接都应是公开项目或公开文档。素材有更新就重新检查。
